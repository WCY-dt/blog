这篇文章用于测试独立网页插件。将此 Markdown 文件复制到 `_posts` 后运行
`bundle exec jekyll serve`，从博客列表打开文章即可看到完整网页。

网页的 HTML、CSS 和 JavaScript 分别存放在
`assets/post/websites/standalone-demo/` 中。这里的 Markdown 正文用于 RSS 和搜索。
